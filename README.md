# EduLink Eswatini — Web Prototype V1

Clean-slate school-management and parent platform prototype.

Includes:
- Home page and original EduLink branding
- School directory and search
- Centre Numbers
- School profiles and fees
- Available spaces by Grade/Form
- School self-registration
- Online admission form and transcript upload field
- Login/role prototype
- School dashboard
- Finance and academic overview
- RBAC design
- Responsive mobile-first UI

Demo data only. Production requires a secure backend, database, authentication, server-side RBAC, document storage, SMS/payment integrations, audit logs, backups and privacy controls.

## Run
npm install
npm run dev

## Build
npm run build

The Vite base path is relative (`./`) for GitHub Pages repository deployments.
